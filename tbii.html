// Project Overview

What is TBII?

TBII is a fully operational dropshipping storefront built end-to-end. It handles the entire customer journey — browsing products, adding to cart, authenticating via Google, completing a Stripe-powered checkout, and receiving an automated order confirmation email — all within a seamless, responsive interface.

Beyond the storefront, the platform includes a live customer chat system, an admin-facing order management flow, and reliable cPanel hosting. Every feature was built from scratch with no e-commerce framework, making it a true demonstration of full-stack engineering capability.

// Problem & Approach

The Challenge & Solution

The Challenge

The client needed a production-ready dropshipping store that handled real payments, protected routes behind authentication, kept customers informed via email automation, and provided real-time support — all without off-the-shelf platforms like Shopify. They wanted full ownership of their codebase and hosting.

The Solution

I designed a custom architecture: a PHP backend managing product data, cart sessions, and order records; Stripe for secure payment intents; Google OAuth for frictionless sign-in; EmailJS for automated order confirmations; and a live chat widget for real-time customer support. The whole system runs on cPanel-managed hosting.

// Outcomes

Results & Takeaways

TBII launched as a fully operational dropshipping store, handling real customer transactions from day one. The project deepened my understanding of payment security, server-side session management, and API orchestration across multiple third-party services.

  • Production-deployed e-commerce store processing live Stripe transactions
  • Secure Google OAuth protecting all authenticated routes and order history
  • Automated email pipeline reducing manual follow-up effort to zero
  • Real-time chat increasing customer confidence and reducing cart abandonment
  • Mobile-responsive storefront delivering consistent UX across all screen sizes
  • Full codebase ownership — no vendor lock-in, no platform fees
