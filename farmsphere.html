// Project Overview

Farm to Buyer — No Middleman

Farmsphere is a full-stack agricultural marketplace that solves a fundamental inefficiency in local food supply chains: farmers earning a fraction of the final sale price because of unnecessary intermediaries. The platform gives farmers a direct digital shopfront, and gives buyers access to fresh produce at fair prices.

The frontend is a React + Vite SPA styled with Tailwind CSS, deployed on Vercel. The backend API is built with Node.js and Express, backed by MongoDB for flexible product and order data, and deployed on Render. The result is a robust, full-stack platform capable of handling real marketplace transactions.

// Problem & Approach

The Challenge & Solution

The Challenge

Farmers in local markets rely heavily on middlemen to move their produce, losing significant revenue in the process. At the same time, buyers overpay for produce that often isn't fresh. There was no accessible digital platform purpose-built for agricultural trade that bridged this gap without complex onboarding or high platform fees.

The Solution

I built a two-sided marketplace where farmers register, list produce with images and pricing, and manage orders — while buyers browse, search by category or location, and place orders directly. A Node.js/Express REST API handles all business logic, with MongoDB storing flexible product and user data. Render hosts the backend; Vercel delivers the frontend globally.

// Functionality

Key Features

Farmer Storefront

Farmers create profiles and list produce with images, descriptions, quantities, and pricing — managed via a clean dashboard.

Search & Filter

Buyers can search produce by name, filter by category (grains, vegetables, fruits) and sort by price or freshness.

Order Management

Full order flow — cart, checkout, order confirmation, and order history for both farmers and buyers.

Authentication

Secure JWT-based authentication with separate farmer and buyer roles, each with tailored dashboards and permissions.

MongoDB Backend

Flexible NoSQL data model handling product listings, user profiles, and orders via a RESTful Express API on Render.

Fully Responsive

Tailwind CSS ensures the marketplace works beautifully on any device — from mobile in the field to desktop in the office.

// Outcomes

Results & Takeaways

Farmsphere stands as the most technically complex project in this portfolio — a full-stack marketplace with a live REST API, persistent NoSQL database, and separate deployment pipelines for frontend and backend. It proved that a solo developer can architect and ship a production-grade two-sided platform.

  • Live full-stack marketplace with separate Vercel (frontend) and Render (backend) deployments
  • RESTful API with full CRUD operations for products, users, and orders
  • MongoDB data model flexible enough to handle varied produce types and order states
  • JWT authentication protecting farmer and buyer routes with role-based access
  • Tailwind CSS delivering a consistent, responsive UI at scale without custom stylesheets
  • Vite's build pipeline enabling rapid iteration and optimised production bundles
